# 搭话模型统一由部署者提供

ADR-0030 让每位用户把一个只用于搭话的模型交给服务器加密保存。这带来两套配置、两条
检查路径和一张只有搭话用到的用户数据表；部署者也无法统一决定搭话用哪个模型。

现在搭话只使用部署者的模型：优先 `.env` 里的 `REACH_OUT_LLM_*`，没有配置时退回
`CHAT_LLM_*`。`REACH_OUT_LLM_*` 可以单独配置，因此纯自带密钥部署也能打开搭话，而文字
回合和通话仍然按 ADR-0028 使用用户自己的 LLM。搭话的费用由部署者承担，不计入用户限额。

App 的设置页、`/api/account/reach-out-llm` 接口和用户模型的检查/保存都移除。旧的
`reach_out_models` 表不再读写，保留到用户删除数据时一并清理，避免升级时丢失已有记录。
