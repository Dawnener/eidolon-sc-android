隐私政策

生效日期：2026 年 10 月 23 日

一、引言

本隐私政策适用于 Eidolon-SC 客户端（以下简称「本应用」）以及为其提供服务的后端部署（以下简称「本服务」）。本服务是由个人部署的非官方粉丝作品，与《偶像大师 闪耀色彩》的版权方及官方无任何关联。

本政策说明我们收集哪些信息、收集目的、共享范围、保存期限，以及您如何查询、删除相关信息。请您在使用本服务前仔细阅读。您仅可通过 GitHub 账号登录本服务。

二、我们收集的信息

我们遵循最小必要原则，仅收集实现服务功能所必需的信息。

  • GitHub 登录信息：您的 GitHub 账号编号、显示名称和邮箱地址。我们不会获取您的 GitHub 密码。
  • 对话内容：您输入的文字、通话中经语音识别转写的文字、角色生成的回复，以及角色发送给您的图片。上述内容仅您本人可见，并随所在对话一并删除，也会进入备份。
  • 对话事件：送礼记录、角色挂断通话等事件记录。此类记录不会提炼为记忆。
  • 通话记录：每通已接通的通话的开始时间与时长，仅用于统计。记录不包含通话内容，我们亦不保存通话录音。
  • 记忆：角色从对话中提炼的关于您的信息。记忆由所有角色共享，您可以在「设置—记忆」中查看和删除。
  • 制作人档案：您设置的称呼、性别、时区和生日（仅月和日）。
  • 好感度：每位角色对您的好感度档位、是否处于冷却状态及冷却解除时间。您仅能查看档位，无法查看具体数值。好感度无法单独删除，删除记忆亦不影响好感度；删除全部数据时一并删除。
  • 玩法数据：您持有的礼物、重置卡、抽奖次数，每日任务进度，成就累计进度与已解锁阶段，以及相应奖励的到账记录。删除历史对话不影响此类数据，此类数据也不包含在导出的数据包中；删除全部数据时一并删除。
  • 搭话设置：您在设置中开启或关闭搭话的状态，以及您已查看的搭话记录。搭话内容属于对话内容的一部分，随所在对话一并删除，并会进入备份和您导出的数据包。
  • 自带密钥：如您填写第三方服务的 API 密钥，该密钥仅保存在您的设备本地，我们不会在服务器上持久化保存。每次回合或通话时，密钥随请求发送至服务器，仅在处理期间驻留内存，不写入数据库、日志或备份。
  • 登录状态与限额计数：用于维持多设备登录状态的会话信息，以及最近 24 小时内您发起的回合数、通话次数和收到的照片数。
  • 运行记录：每个回合、每次通话和每次搭话所对应的角色、发生时间、处理结果（成功、失败、被拒绝等）、通话时长与结束原因（包括角色主动挂断）；内容判断模型对每个回合的判断结果（例如该语句使角色产生的情绪、是否被判定为不当内容或操纵行为、是否因此进入冷却）；所使用的服务与模型、是否使用自带密钥、用量（例如 token 数）、是否发生错误及处理耗时。角色发送图片时，还会记录图片描述标签中被安全策略移除的数量及类别，但不记录标签本身。搭话记录会包含您是否作出回应；完成每日任务或解锁成就阶段时，会记录对应任务、阶段或角色。上述记录不包含您输入的原话和角色的回复，不记录密钥，也不记录自带语言模型服务的地址和模型名称。运行记录保存 90 天。
  • 备份：上述数据每日加密备份一次，存放于部署者的私有云存储中，每份保留 30 天，仅用于服务器故障后的恢复。

三、信息的使用

我们使用上述信息以提供对话、通话、记忆、礼物与成就等功能，执行使用限额与安全策略，排查故障，并统计服务运行情况与费用。我们不会出售您的个人信息，也不会将其用于本政策所述目的之外的用途。

四、信息的共享与第三方处理

为实现服务功能，部分信息会交由以下第三方服务处理。实际启用的服务取决于部署者的配置以及您是否使用自带密钥。

  • GitHub：您通过 GitHub 登录时，GitHub 会知悉您使用其账号登录本服务。登录流程受 GitHub 自身隐私政策约束。
  • 语言模型服务：扮演角色、提炼记忆和生成对话标题时，对话内容及相关记忆会发送至语言模型服务。如您填写了自己的语言模型密钥，相关内容将发送至您选择的服务；如另行配置了后台模型，提炼记忆和生成标题时也会使用该模型；如未填写，则发送至部署者配置的服务。开启搭话功能后，即使您不在线，服务器也会将相关对话和记忆发送至部署者配置的服务，以生成角色的主动消息；即使您填写了自带密钥，该情形亦不例外。
  • 内容判断模型：每个回合中，您输入的语句及最近若干回合的对话会发送至部署者配置的判断模型（例如 TypeSafe 的 Jev，经 OpenRouter 等渠道转发；或 Cloudflare 的 Clef），用于判断是否需要检索剧情或资料、您是否在请求照片，以及该语句对好感度的影响。通话过程中，角色的回复也会分段发送至该模型以判断情绪。判断模型始终由部署者提供，使用自带密钥不影响这一安排。
  • 语音识别与合成：通话时，您的语音会发送至部署者选择的语音识别服务（Soniox 或阿里云百炼）转写为文字；角色的回复会发送至 Fish Audio 合成语音。阿里云百炼不会使用您的语音训练模型，但会在一定期限内保存语音数据，存储地点为中国内地或新加坡，具体取决于部署者的账号设置。
  • 向量化与重排服务：为在对话中检索相关剧情与记忆，您输入的语句和记忆会发送至部署者选择的向量化服务（硅基流动或 Google Gemini）及重排服务（硅基流动）。
  • 图像生成服务：角色向您发送图片时，用于描述图片的英文标签（包括地点、服装、动作，由角色根据对话生成）会发送至部署者配置的图像生成服务（NovelAI 或其中转服务），不会发送您输入的原话。如您填写了自己的图像生成密钥，相关内容将发送至您选择的服务。

如您使用自带密钥，相应内容将发送至您自行选择的第三方服务，并适用您与该服务商之间的协议。第三方服务对信息的保存和删除受其自身隐私政策约束。

五、管理者的访问权限

管理者可以查看您的登录方式（GitHub）、显示名称、邮箱地址、注册时间与最后活跃时间、最近 24 小时至 30 天内的回合和通话次数（包括因限额被拒绝的次数）、自带密钥的使用占比、是否被封禁及封禁备注，以及是否被单独调整限额。

管理者无法查看您与角色的对话内容、角色发送的图片及图片描述标签、角色提炼的记忆、您的制作人档案、各角色对您的好感度与冷却状态，以及您的礼物、重置卡、抽奖次数、每日任务和成就。好感度仅以全体用户汇总统计的形式提供，管理者无法查看或调整特定用户的好感度。

管理者由部署者指定，仅可在其专属后台中管理本服务。运行记录会汇总为全站统计，用于检查服务可用性、使用规模与费用情况。管理者可以封禁用户或单独调整某位用户的限额；被封禁的用户将无法登录，进行中的通话将被终止，其数据保持不变。

六、保存期限

对话及相关数据保存至您主动删除；运行记录保存 90 天；备份保存 30 天；被封禁用户删除后留下的登录身份哈希值长期保存，用于阻止同一身份再次注册。第三方服务保存信息的期限适用其各自的隐私政策。

七、您的权利

您可以在应用内查看和删除记忆，逐段删除历史对话，或通过「设置—删除我的全部数据」删除您的全部数据。正在进行的对话需在新对话开始后才能删除；开启新对话后，此前的对话可在对话页的历史记录中逐段删除。删除操作会立即从线上环境中彻底移除相关数据，而非仅作标记；删除后，您的记忆、对话、制作人档案、登录方式、登录状态和限额计数均会被删除，所有设备将退出登录。

已完成备份中的副本将在备份到期后删除，最长不超过 30 天。删除全部数据不会删除您已导出的数据包。被封禁用户的数据被删除后，我们会保留其登录身份编号经加密哈希后的结果，不包含姓名和邮箱，用于防止该身份再次注册。

删除完成后，您使用同一 GitHub 身份再次登录时，将被视为一位全新的用户。您的运行记录不会随账号删除，但将不再与您关联，也无法重新对应到您，并会在 90 天后照常删除；如此可保证全站统计不因个别用户离开而失真。您也可以联系部署者代为删除，效果相同。

本服务仅支持 GitHub 登录，因此不会通过其他登录方式识别或关联您的身份。

八、未成年人保护

本服务不面向未满 13 周岁的儿童。若您未满 13 周岁，请勿使用本服务。

九、信息安全

我们采取合理的技术与管理措施保护您的信息，包括对备份进行加密、避免在日志中记录对话原文和记忆原文。但互联网传输与存储无法保证绝对安全，请您妥善保管自己的账号与设备。

十、政策更新

我们可能根据服务调整或法律要求适时更新本政策。更新后的政策将在本页面公布，并注明生效日期；如变更对您的权利有重大影响，我们会以显著方式提示。
